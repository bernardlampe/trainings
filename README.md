Vulnerability research training material based on Linux and Android, written in 2019 and reflecting the industry at that time.

- `android/` — Android and mobile auditing (kernel/SELinux background, rooting, attack surface, emulation)
- `binary_re/` — binary reverse engineering (object formats, disassemblers, decompilers, anti-reversing)
- `debugging/` — the debugger as a research instrument (breakpoints, watchpoints, remote/kernel sessions)
- `exploitation/` — from primitive to exploit (code reuse, infoleak, allocator grooming)
- `fuzzing/` — fuzzing (mutation, generative, feedback, triage, corpus)
- `linux_auditing/` — Linux kernel auditing (attack surface, drivers, kernel fuzzing, elevation)
- `linux_secmodel/` — Linux and Android security models (credentials, capabilities, LSM/MAC, namespaces, seccomp)
- `source_auditing/` — source auditing (bug patterns, mitigations, reporting)
